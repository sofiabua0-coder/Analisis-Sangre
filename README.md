
# Aprende a Leer Análisis de Sangre

> Web educativa para aprender a interpretar resultados de laboratorio: guía, calculadora interactiva, glosario y casos clínicos.

---

## Qué podés aprender aquí

- Interpretar los resultados de un hemograma completo.
- Entender valores clave como hemoglobina, hematocrito, glucosa, creatinina y más.
- Saber qué significa un valor alto o bajo en cada prueba.
- Revisar casos clínicos reales con explicación de los resultados.
- Usar una calculadora interactiva para aprender cómo comparar tu valor con el rango normal.
- Consultar un glosario con términos médicos importantes.

---

## Características principales

- Análisis completos con descripción y significado.
- Valores normales por prueba y rangos de referencia.
- Explicación de qué pasa cuando un valor está alto o bajo.
- Casos clínicos reales para practicar la interpretación.
- Calculadora interactiva por análisis y grupo (hombre / mujer / adulto).
- Tema claro/oscuro y diseño responsive para teléfonos.

---

## Cómo usar la página

1. Abrí `index.html` en tu navegador.
2. Navegá entre las secciones: Análisis, Valores, Casos, Calculadora y Guía.
3. Usa el buscador para encontrar rápidamente cualquier análisis.
4. En la calculadora, seleccioná la prueba y escribí tu valor para ver la interpretación.
5. Lee los casos clínicos para ver ejemplos reales de resultados y su significado.

---

## Archivos principales

- `index.html` — interfaz de la web.
- `styles.css` — estilos y diseño adaptativo.
- `app.js` — lógica de interacción y navegación.
- `data.js` — datos de pruebas, rangos y casos clínicos.

---
